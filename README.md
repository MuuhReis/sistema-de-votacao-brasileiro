# sistema-de-votacao-brasileiro
Projeto desenvolvido em Java que verifica a situação do voto de uma pessoa com base na idade, seguindo as regras da legislação brasileira, com interação via terminal.

⸻

Funcionalidades
• Entrada de dados do usuário:
  • Nome
  • Ano atual
  • Ano de nascimento
  • Cálculo automático da idade
•Verificação da situação do voto:
  • Voto não permitido 🚫
  • Voto opcional ⚖️
  • Voto obrigatório ✅
  • Validação de ano de nascimento inválido

⸻

Tecnologias utilizadas
  • Java
  • Classe Scanner para entrada de dados
  • Estruturas condicionais (if/else)
  • Métodos para organização do código

⸻

Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:
  • Lógica de programação
  • Uso de métodos para modularização
  • Estruturas condicionais (if/else)
  • Validação de dados de entrada
  • Interação com o usuário via terminal

⸻

Exemplo de execução

O usuário informa seu nome, ano atual e ano de nascimento. O programa calcula a idade e exibe se o voto é obrigatório, opcional ou não permitido.
